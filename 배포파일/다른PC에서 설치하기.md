# 다른 PC에서 일용할 양식 사용하기

1. 같은 Microsoft 계정으로 OneDrive에 로그인합니다.
2. `OneDrive\0VibeCoding\DailyBread` 폴더가 모두 내려올 때까지 기다립니다.
3. `일용할양식 시작.cmd`를 더블클릭합니다.
4. 앱이 없으면 설치 화면이 열립니다. 기본 설정 그대로 설치합니다.
5. 다음부터는 바탕화면이나 시작 메뉴의 `일용할 양식`을 실행합니다.

개인용 설치파일이라 Windows가 보호 경고를 표시할 수 있습니다. 파일 이름이 `일용할 양식_..._x64-setup.exe`인지 확인한 뒤 `추가 정보` → `실행`을 선택합니다.

묵상과 성경 데이터는 `0VibeCoding\DailyBread\데이터`에 있으며 여러 PC에서 공유됩니다. 앱 프로그램 자체는 각 PC의 로컬 영역에 설치되므로 OneDrive가 개발용 파일을 동기화하지 않습니다.

문제가 생기면 `일용할양식 시작.cmd`를 다시 실행하고, 나타난 오류 문장을 복사해 AI에게 전달합니다.
